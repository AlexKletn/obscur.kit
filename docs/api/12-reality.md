# 12 — What is not wired

A type existing is not evidence that anything calls it, and a doc comment
asserting the wiring is not evidence either. This page is the list of things that
compile, pass their tests, and have **no production caller** — plus the things
that are real but stop at a named boundary.

**Method.** For each entry: grep the symbol across `crates/`, excluding its own
crate and excluding `tests/`. A crate-level entry additionally checks which
`Cargo.toml` files depend on it. Verified at the commit that added this page;
it decays as soon as someone adds the caller.

**Last re-measured 2026-08-04, at `628d7f40` plus the uncommitted debt-closure
working tree.** Method: every row re-grepped and re-read against the source, with
the file and line that settles it written into the row. Gates at that
measurement: `cargo fmt --all --check` clean; `cargo test --workspace` **6439
passed / 0 failed / 9 ignored**; `xtask check` and `xtask consumer` both pass;
`cargo clippy --workspace --all-targets` **360** warnings. What the campaign did
to this page is recorded in `docs/debt-closure.md`; the short version is that
**three rows were closed by deleting their subject** (listed as four entries at
the bottom, since one row named two independent caches) and are summarised there
rather than kept in the tables, and thirteen rows had moved and are
corrected in place — each marked `~~old claim~~ — **CLOSED**`, or split so that
each half says what is actually so.

**Citations re-anchored 2026-08-07.** Every `file:line` on this page was re-read
against the working tree. **No verdict changed** — the nine that had drifted were
all pushed down by unrelated code landing above them, and each still names what
the row says it does. Corrected: `kit_bootstrap.rs` `:181`→`:194` and
`:296-318`→`:306-332`, `condition_lowering.rs` `:52-63`→`:93-105`,
`style_phase.rs` `:118`→`:122`, `restyle_phase.rs` `:158`/`:209`→`:166`/`:219`,
`paragraph_shaper.rs` `:175-190`→`:165-189`, `compose_phase.rs`
`:79-86`→`:83-90`, `construction.rs` `:81`→`:86`, `ui_runtime.rs` `:848`→`:859`.
Everything else on the page — every `obscur-layout` citation including all nine
`\.constrain(`-family sites, the whole devtools `endpoint.rs` set, and the portal
row's `hit_testing.rs` anchors — still lands where it said it would. That a citation can rot without a
verdict rotting is the argument for the page's own closing rule: cite the symbol
in the prose as well as the line, so a reader can re-find it when the line moves.

The lesson the `ch` row taught is worth stating at the top: **a page that
over-claims brokenness misleads a reader deciding what to build on just as badly
as one that over-claims completeness.** And the lesson the *clamp* row taught,
twice: **grepping a symbol you already suspect cannot enumerate.** That row was
widened from "flex" to "flex and grid" by one re-measure and was still one word
too narrow, because the second pass grepped the two algorithms it had been told
about instead of grepping the *call*. Do not trust a row here without re-running
its grep, and prefer a grep that enumerates over one that confirms.

## Unwired by construction: the re-export barrel

`obscur-kit/src/lib.rs` is `pub use X as y;` and nothing else. A crate whose only
path to the outside is that file is exported, compiles, and is called by nothing.

The table below is what the check found. Three rows are still that shape; the
fourth, `obscur-testkit`, used to be the worst of them and no longer is — it is
kept here so the correction is visible next to the claim it replaces.

| **UA stylesheet vocabulary** | **Was: a third of the sheet matched nothing.** This page's own subject, in the one place a reader would never look for it — a *stylesheet* is not a type, so no grep for a zero-caller symbol would ever have found it. **Seven of the sheet's 48 rules** could not reach anything the Rust API builds: `table`, `th`, `td`, `tr:hover` against a widget whose rows and cells carried a private `role` *property* CSS cannot see; `img` against a primitive that emitted no name at all; `.placeholder` against a class nothing emits, when §4.16 makes the hint a synthetic part reachable only through `::part()`; `.select-option.disabled` against a per-option state `Select` does not have. | **Base-element control tags** | **Was: *"they bind to the shipped widget's `ComponentId`, but nothing registers a factory for the built-in widget ids, so the widget's own `view()` — its indicator sub-part, its `:checked` class — never runs. The id is a handle with nothing mounted under it."*** Five of the six now mount, and the sixth is a refusal with a reason. `<input>`, `<textarea>`, `<checkbox>`, `<radio>`, `<select>`, `<table>` bind to the shipped widget's `ComponentId` instead of falling through to `Container`, so an authored `<checkbox>` is a checkbox to the cascade, to hit-testing and to the accessibility tree. **`<checkbox>`, `<radio>`, `<select>`, `<input>` and `<textarea>` are now also mounted controls** — a `…Props` + `…Component` + `…Factory` trio ships in `obscur-widgets` for each, `KitBootstrap::install_builtin_components` registers them by default, and `App`/the layer runner call it. The four share one shape, and it is worth naming because it is what this campaign
mostly found: **not unanalysed code, but code whose successor already shipped past

one, and in two of them the dead type's own documentation had already worked out
the whole case and stopped at "the decision is the owner's".

## What this page is not

The rows distinguish active behavior from exported APIs and document intentional
approximations such as the CPU renderer's handling of GPU effects.

If you need one of these wired, the gap is usually small and specific — most
entries above are "no caller", not "no implementation".

It is also **not a page you may read without checking**, and the two re-measures
behind it are the argument. The 2026-08 pass found thirteen rows that had moved
and nobody had come back — in both directions. `ch` had been fully closed for
some time while this page still told a reader it contributed `0`; `@container`
had grown a real lowering while this page still named the `Never` it no longer
emits; the plugin tier was described through a `sandbox` module that does not
exist. But `obscur-system` had *fewer* adapters than claimed, and the flex
border-box clamp turned out to be a grid defect too.

The 2026-08-04 pass then found that the pass before it had **itself** left three
things wrong: the clamp row was widened once and was still too narrow (four
algorithms, not two), the `ch` row named three of four production supply sites,
and the gamepad row counted the haptic file's tests as its own. None of those was
carelessness; all three are the same mechanical limit, which is the most useful
thing on this page:

> **A grep that confirms a symbol you already suspect cannot enumerate.** It
> finds the first hop and stops. Three separate rows were fixed only by grepping
> the *call* (`\.constrain(`), the *construction* (`ShapedChMetrics::new`) or the
> *directory* rather than the name someone had already written down — and
> `HitTest`, `HitChain` and the whole `pass/` island were absent from this page
> for exactly as long as nobody happened to suspect them.

The convention when you find one: strike the old claim, write what the
measurement was, and cite the file and line — so the next reader can tell a
verdict from a memory. And when the row is a *count* or a *set*, enumerate it;
do not confirm it.
