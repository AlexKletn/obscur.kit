# Obscur Kit

[English version](README.md) · [Как участвовать в разработке](CONTRIBUTING.ru.md)

Obscur Kit — инструментарий на Rust для построения интерфейсов с сохраняемым
деревом. Представление можно описать на Rust или в `.okui`, оформить с помощью
CSS и отрисовать в окне или вне экрана. Приложения используют
[фасад `obscur-kit`](crates/facade/obscur-kit/).

Среда выполнения согласует представления с сохраняемым деревом, применяет
каскад, рассчитывает раскладку потока, Flexbox и Grid и строит сцену для
отрисовки. В кит также входят виджеты, шейпинг текста через HarfRust, виртуальные
списки, переходы и жесты с указанием источника: сенсорный экран или тачпад.

## Запуск примеров

Из корня рабочего пространства запустите оконный счётчик или отрисуйте
демонстрацию возможностей в PNG на CPU.

```sh
cargo run -p obscur-kit --features full --example hello_app
cargo run -p obscur-kit --example capabilities_png
```

Для оконного примера нужны дисплей и GPU-бэкенд. Основная настольная платформа —
Linux. Для панелей Wayland нужен композитор с поддержкой `wlr-layer-shell`.
Доступность системных интеграций зависит от включённых фич Cargo и платформы.

## Интеграция в приложение

- [Точки входа](docs/api/01-entry-points.md) описывают `App`, встраивание среды
  выполнения и работу без дисплея.
- [Ввод и жесты](docs/api/06-input.md) описывают источники и обработку жестов.
- [Встраивание](docs/api/10-hosting.md) описывает API для хоста.
- В [манифесте фасада](crates/facade/obscur-kit/Cargo.toml) перечислены
  опциональные бэкенды, включая Vello, winit, layer shell, AccessKit и исполнение
  плагинов в отдельных процессах или через WASM. Точки интеграции для плагинов
  определяет приложение.

Справочник Rust API собирается командой
`cargo doc --no-deps -p obscur-kit --features full`.

## Репозиторий

- В [`crates/`](crates/) находятся доменные крейты, среда выполнения, фронтенд,
  компоненты, адаптеры, крейты плагинов и публичный фасад.
- В [`tools/`](tools/) находятся проверка архитектуры, клиент DevTools,
  языковой сервер для `.okui` и CLI для работы с плагинами.
- В [`specs/`](specs/) описаны устройство кита и архитектура крейтов. Состояние
  реализации на момент проверки зафиксировано в [аудите соответствия](docs/conformance-audit.md).

Проверки и соглашения описаны в [гайде для участников](CONTRIBUTING.ru.md).
