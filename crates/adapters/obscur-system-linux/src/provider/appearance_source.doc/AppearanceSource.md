Where to read the desktop's appearance from — the integrator's choice.

There is no single right answer on Linux, which is why this is a choice and not
a detail. The three sources know different things and are available in
different situations, and an application that ships to one desktop should be
able to say which it means.

Naming one is binding: a named source that cannot answer answers *nothing*
rather than falling through, because a silent fall-through would look like the
named source had worked.
