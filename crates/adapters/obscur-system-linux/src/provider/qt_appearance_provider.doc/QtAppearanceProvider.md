Appearance as KDE states it, read straight out of `kdeglobals`.

The most complete source on this platform, and the cheapest: no process, no bus,
one file read. It is the only one that states a palette, which is why
[`support`](Self::support) answers
[`Native`](obscur_capability::SupportLevel::Native) when the file exists while
the other two answer `Limited`.

Also read by qt5ct/qt6ct sessions and by anything else that follows KDE's
config, so "Qt" here names the convention rather than the toolkit.
