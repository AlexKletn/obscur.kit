Expands supported `background` values into image, color, size, position,
repeat, blend-mode, clip, origin and attachment declarations. Each layer can specify an image, repeat,
position with an optional slash-separated size, attachment, and one or two
box keywords. Only the final layer may
include a color. Omitted values are initialized per layer. A standalone custom
property follows the color-value path. CSS-wide keywords apply to every
expanded longhand.
