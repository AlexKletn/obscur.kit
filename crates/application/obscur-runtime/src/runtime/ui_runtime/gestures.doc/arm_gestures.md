Arms whatever this `Down` speculatively started: a pan for the scroll
container a **direct** contact landed in, and a long press for a target
that binds one (spec §6.16).

Both, or either, or neither — [`GestureArming`] decides which from the
frame, and the two coexist: whichever the finger goes on to do, travel or
wait, rules the other out. A tap short of both is still a tap.

Points arrive in **content space before each container's own scroll
offset** is folded in, because the scroll-mapped point moves as the
container scrolls and tracking it would feed the pan its own output.
