The stored offset of `node`, floored at zero.

The read for a caller that has **no** live [`ScrollContainer`] to clamp
against — the virtual-list paths, which key on the container a list
realized its spacers into rather than on a resolved container. Prefer
[`clamped`](Self::clamped) wherever the container is at hand: this cannot
re-clamp an offset that the current layout no longer allows.
