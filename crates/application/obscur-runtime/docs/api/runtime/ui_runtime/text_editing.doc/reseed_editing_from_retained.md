Applies the controlled-input reseed gate to the focused session after a
structural frame's reconcile, when the retained tree already carries the
app's value.

[`ControlledReseed::decide`] owns the discriminator — which of "leave the
buffer alone", "the session's own edit came back" and "the app rewrote this
field" a frame's retained value means — and its documentation is the written
account of the controlled-input model. This is the write half: it seats the
decision on the session and re-derives what a changed buffer invalidates.
