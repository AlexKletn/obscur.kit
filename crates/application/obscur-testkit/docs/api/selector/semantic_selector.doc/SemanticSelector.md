Nodes selected out of the retained tree by a semantic property rather than by a
path.

[`NodePath`](crate::selector::NodePath) answers "which node is at root → child 0",
which is the right question when a fixture's shape is fixed. It is the wrong
question when the shape is what the test is asking about: a realized virtual
window has however many rows the viewport bought, at depths nothing has promised.
Counting the nodes that carry a class answers that directly.
