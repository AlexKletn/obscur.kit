Mounts the built-in `checkbox` under [`Checkbox::COMPONENT_ID`].

This is the shape every shipped widget's factory takes: four methods, no
state, every answer delegated to the widget's own id and its props
struct's `contract()`. It is written out concretely rather than generated
because there is one of it; when a second and third exist and the variation
between them is visible, that is the moment to decide whether a generic
adapter is describing something real.
