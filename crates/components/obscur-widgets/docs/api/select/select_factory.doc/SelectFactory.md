Mounts the built-in `select` under [`Select::COMPONENT_ID`].

The third instance of the shape [`CheckboxFactory`] introduced: four methods,
no state, every answer delegated to the widget's own id and its props struct's
`contract()`. All three now agree line for line, and the variation between them
is exactly three type names — which is the measurement that says a generic
adapter would be longer than the thing it replaced, not the intuition that it
would.
