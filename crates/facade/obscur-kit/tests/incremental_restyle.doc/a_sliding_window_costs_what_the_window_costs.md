The stated origin use case as a measurement: a 30-row window sliding one row per frame over a long model, 3000 frames.

Not an oracle — it prints, it does not assert, because a frame time is a property of the machine it runs on. What it is for is the shape: with per-node state pruned on the reconciled frame, both the resident set and the frame time must be flat in the frame number, since the live tree is. A line that climbs means something is again keyed by nodes ever removed rather than nodes present.
