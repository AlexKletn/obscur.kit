The whole of the finding, in one assertion: a face the application supplied
under the name `Figtree` is the face a sheet saying `font-family: Figtree`
draws in.

The control paragraph is what keeps it honest. A set with one face in it would
satisfy the first assertion for the wrong reason — everything would draw in
that face — so the second one requires that text which does *not* name the
family draws in something else.
