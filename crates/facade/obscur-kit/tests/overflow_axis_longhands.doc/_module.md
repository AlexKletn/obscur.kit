An author can state one overflow axis.

`overflow-x` and `overflow-y` are the storage and `overflow` is a shorthand over
the pair, so a sheet that scrolls one direction — `overflow-y: auto`, the
commonest way to write a scrolling panel — reaches the scroll path. It did not:
there was a single `overflow` property, the longhand named nothing, and the
declaration was dropped as unsupported, leaving a list that overflowed visibly
and refused the wheel.
