A name identifying something registered with the runtime — a painter, and in
time whatever else the `-obscur-` namespace comes to name.

It survives to computed value as the TEXT it was written as, where a
[`Keyword`](PropertyValue::Keyword) could not: a keyword's symbol is minted by
the interner of whichever stylesheet happened to be compiling, so the same word
in two sheets is two different symbols and neither one matches a registry key.
