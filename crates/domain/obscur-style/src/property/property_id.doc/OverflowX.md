The `overflow-x` property (Keyword-valued: `visible` (initial) / `hidden` /
`clip` / `scroll` / `auto`; NOT inherited). See the reserved `OVERFLOW_*`
handles in [`crate::property::layout_keyword`]. It states the INLINE axis
alone; the `overflow` shorthand expands to this longhand and
[`PropertyId::OverflowY`], which are the storage. A value other than
`visible` clips the element's subtree to its box. The kit carries one scroll
offset per box — the block axis — so an inline-axis `scroll` / `auto` clips
and establishes the container without being scrollable by the user.
