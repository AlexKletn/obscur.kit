How much of an answer this source can give.

[`Native`](obscur_capability::SupportLevel::Native) for a source that answers
the whole shape, [`Limited`](obscur_capability::SupportLevel::Limited) for one
that answers part of it — a session that states a scheme and no palette is
`Limited`, and saying so is what stops a host reading the missing colours as
"the desktop chose none" — and
[`Unavailable`](obscur_capability::SupportLevel::Unavailable) where there is
nothing to read.
